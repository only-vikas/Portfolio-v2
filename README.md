## 🎨 Design Philosophy

### **UI/UX Approach**

This portfolio embodies a **cinematic, premium design philosophy** with the following characteristics:

- **Immersive Visual Hierarchy** — Bold typography paired with subtle animations
- **Glassmorphism & Gradients** — Modern, layered design elements with depth
- **Micro-interactions** — Magnetic buttons, scroll-triggered animations, hover effects
- **Dark-to-Light Transitions** — Thematic section backgrounds for visual rhythm
- **Performance-First** — Lazy loading, optimized images, efficient animations
- **Accessibility** — WCAG-compliant, semantic HTML, keyboard navigation

### **Design Tokens**

- **Color Palette**: Deep blacks, purples, blues, with vibrant gradients (violet → fuchsia → orange)
- **Typography**: Bold, modern sans-serif with variable font weights
- **Spacing**: 8px-based scale for consistent spacing
- **Animations**: GSAP for complex sequences, Framer Motion for component-level motion

## 🚀 Getting Started

### **Prerequisites**
- Node.js 18+ (compatible with v20)
- npm, yarn, pnpm, or bun

### **Installation**

```bash
# Clone the repository
git clone https://github.com/only-vikas/Portfolio-v2.git
cd Portfolio-v2

# Install dependencies
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

### **Development Server**

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

The page auto-updates as you edit files. Start by modifying `app/page.tsx`.

### **Building for Production**

```bash
npm run build
npm start
```

### **Linting**

```bash
npm run lint
```
